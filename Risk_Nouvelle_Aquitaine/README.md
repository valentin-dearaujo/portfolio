# Prévention des risques à Bordeaux Métropole

Ce projet a été réalisé en équipe de 6 personnes dans le cadre d'une SAÉ (Situation d'Apprentissage et d'Évaluation) à l'IUT de Bordeaux. Il se base sur le défi officiel proposé par **OpenDataUniversity** sur la plateforme gouvernementale : [Prévention des risques à Bordeaux Métropole](https://defis.data.gouv.fr/defis/prevention-des-risques-a-bordeaux-metropole).

⚠️ **Note : Projet à but de démonstration (Non exécutable)**

Ce dépôt fait partie de mon portfolio. Il est mis à disposition uniquement pour présenter notre code source, notre approche analytique et notre méthode de travail. 

**Le projet ne peut plus être exécuté localement** pour la raison suivante :
- **Données volumineuses exclues :** Les fichiers sources originaux (Open Data issues de Gaspar, Météo-France et Atmo Nouvelle-Aquitaine) représentent environ 4 millions d'enregistrements. Ils dépassent largement les limites de stockage de GitHub et ont été retirés du dépôt.

## Objectif du dépôt

Bien que les scripts ne puissent pas être lancés "à vide", l'intégralité du code source (qui a été entièrement produit par notre équipe[cite: 1]) reste consultable. Ce dépôt permet d'observer :
- Les scripts Python de nettoyage, de filtrage et de consolidation de données massives.
- La logique d'analyse statistique appliquée aux données environnementales (régressions linéaires, histogrammes).
- La structuration du code pour un projet data collaboratif.

## Technologies et outils utilisés
- Python
- Pandas (Traitement et analyse de données)
- Bibliothèques de visualisation de données (Matplotlib / Seaborn)
- Open Data (Exploitation de jeux de données gouvernementaux)
